# Budget: versioni dell'app

Qui ci sono solo le versioni pubblicate dell'app Android **Budget** (file APK) e `version.json`,
che l'app legge una volta al giorno per sapere se c'è un aggiornamento.

Per installarla: scarica l'APK dell'ultima versione da **Releases** e aprilo sul telefono.
Gli aggiornamenti successivi arrivano dall'app stessa ("Aggiorna"), che controlla l'impronta SHA-256 del file.
